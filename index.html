Quick start

Read the tutorial board at camp. Take the Practice Sword and Barbarian Cloth from the chest and equip both before heading to Terra.

Save before leaving. Use the in-game menu to save, then choose Continue next time. Use the same browser and avoid clearing site data if you want to keep your saves.
